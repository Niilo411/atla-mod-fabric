# Moved to [elemental-paths](https://github.com/Niilo411/elemental-paths)

This repository is archived. **Elemental Paths** (formerly Atla Mod) now lives in one
repository for every mod loader:

**https://github.com/Niilo411/elemental-paths**

- **Downloads** for every loader and Minecraft version: the
  [Download table](https://github.com/Niilo411/elemental-paths#download) at the top of its README.
- **The Fabric 1.21.11 and Fabric 26.3 source code** is on the `fabric-1.21.11` and `fabric-26.3` branch there.
- Every release from this repository was copied over, tagged with its loader
  (for example `fabric-26.3-v3.1.2`).

The releases below still download, but new versions will only be published in elemental-paths.
